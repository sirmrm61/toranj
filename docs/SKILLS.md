# لیست مهارت‌های مورد نیاز پروژه وب‌سایت مزون لباس عروس

بر اساس PRD و TRD پروژه. اولویت: **الزامی** = بدون آن پروژه پیش نمی‌رود، **مهم** = کیفیت یا ریسک را مستقیم تحت تأثیر می‌گذارد، **اختیاری** = در صورت بودجه یا فاز بعد.
